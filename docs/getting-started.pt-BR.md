# Primeiro uso

[English](getting-started.md)

1. Abra o Nocturne Studio e conclua a apresentação inicial.
2. Selecione uma pasta de projeto. A seleção explícita autoriza somente essa
   raiz.
3. Abra **Configurações > IA**.
4. Conecte uma conta ChatGPT pelo Codex CLI, configure uma API
   OpenAI-compatible ou registre um runtime local.
5. Atualize o catálogo, escolha um modelo e associe-o ao workspace.
6. Crie uma conversa e comece em Review Mode para uma análise somente leitura.
7. Revise evidências e sugestões antes de aceitar, adiar, rejeitar ou preparar
   uma aplicação.
8. Aprove memórias somente quando forem úteis e duráveis.

Na próxima abertura, conversas, decisões e memórias permanecem no banco local.
Se o projeto foi movido, use **Localizar pasta**. Se estiver ausente ou sem
leitura, o histórico continua disponível, mas o workspace fica desautorizado até
uma nova seleção explícita.

Backups restauram dados, não arquivos do projeto nem autorização do workspace.
Selecione o projeto novamente depois da restauração.
