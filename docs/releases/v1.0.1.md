# Nocturne Studio v1.0.1

`v1.0.1` consolidates the final release-candidate line and hardens release
infrastructure. It establishes `gustavomfg/nocturne-studio` as the canonical
distribution and updater repository while preserving compatibility for the
published `v1.0.0` client through the GitHub rename redirect.

This is a release-infrastructure update, not a new feature phase. The minimum
supported Codex CLI remains `0.145.0`.
