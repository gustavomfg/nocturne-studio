# Nocturne Studio v1.0.2 (candidato)

`v1.0.2` é uma preparação de candidato ainda não publicado após a linha estável
publicada `v1.0.1`. Este documento é uma fonte futura de notas da release, não
evidência de que exista uma tag ou GitHub Release.

## Escopo desde a v1.0.1

- Estende Change Control, recuperação operacional, inteligência de projeto e
  semântica e Engineering Intelligence com limites adicionais de consistência
  e evidência.
- Amplia a cobertura de persistência, validação, renderer e pacote para o fluxo
  atual do workspace de engenharia.
- Preserva o modelo local-first, a autorização explícita do workspace e a
  fronteira de aprovação do desenvolvedor.

## Política de distribuição

Os alvos configurados para Linux, Windows x64 e macOS ARM64 continuam sendo a
fonte de verdade dos futuros artefatos. Os manifestos de checksum Linux são
assinados no ambiente protegido de release. Os artefatos Windows e macOS são
distribuídos com checksums, mas permanecem sem assinatura e sem notarização sob
a política atual.

## Compatibilidade e limite de publicação

O CLI Codex mínimo suportado continua sendo `0.145.0`; `0.146.0` é a versão
recomendada e verificada. O contrato do App Server continua experimental, e
versões mais novas precisam passar pelo handshake de compatibilidade em tempo
de execução.

A publicação real da `v1.0.2` ainda exige o SHA exato do candidato, gates
protegidos de fonte/renderer/persistência/pacote, inventário multiplataforma,
metadata do atualizador e autorização explícita do workflow de release. Este
follow-up não cria tag, release nem asset enviado.
