# Nocturne Studio v1.0.1

`v1.0.1` consolida a linha final do release candidate e reforça a infraestrutura
de release. Ela estabelece `gustavomfg/nocturne-studio` como repositório
canônico de distribuição e atualização, preservando a compatibilidade do
cliente `v1.0.0` publicado por meio do redirect de rename do GitHub.

Esta é uma atualização de infraestrutura de release, não uma nova fase de
funcionalidades. O CLI mínimo suportado do Codex continua sendo `0.145.0`.
