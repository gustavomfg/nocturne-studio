# Nocturne Studio v0.9.5-beta

## Overview

This release focuses on stability, consistency, and quality improvements across the application. It represents a significant stabilization milestone on the path to the 1.0.0 release.

## Highlights

- Improved suggestion lifecycle consistency.
- Fixed terminal suggestion states in the Suggestions panel.
- Improved UI consistency between suggestion cards and the detailed dialog.
- Updated project health recalculation flow.
- Improved renderer stability.
- Expanded automated test coverage.
- Cross-platform validation completed successfully (Linux, Windows, and macOS).

## Fixed

- Fixed suggestion actions remaining available after a suggestion was resolved.
- Fixed visual regression detected by Playwright snapshot tests.
- Fixed inconsistencies between suggestion state and available actions.

## Validation

- ✅ TypeScript
- ✅ Unit tests
- ✅ Playwright
- ✅ Visual snapshots
- ✅ GitHub Actions
- ✅ Linux
- ✅ Windows
- ✅ macOS

## Notes

This release is considered a stabilization milestone before the upcoming 1.0.0 release.

## Compatibility

- Minimum supported Codex CLI version: `0.145.0`
- Recommended Codex CLI version: `0.146.0`
- Newer Codex CLI versions are detected automatically when they satisfy the
  minimum and pass the App Server handshake.
