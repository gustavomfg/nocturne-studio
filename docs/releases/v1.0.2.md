# Nocturne Studio v1.0.2 (candidate)

`v1.0.2` is an unreleased candidate preparation after the published `v1.0.1`
stable line. This document is a future release-note source, not evidence that a
tag or GitHub release exists.

## Scope since v1.0.1

- Extends Change Control, operational recovery, project and semantic
  intelligence, and Engineering Intelligence with additional consistency and
  evidence boundaries.
- Extends persistence, validation, renderer and package coverage for the
  current engineering workspace flow.
- Preserves the local-first model, explicit workspace authorization and
  developer approval boundary.

## Distribution policy

The configured Linux, Windows x64 and macOS ARM64 targets remain the source of
truth for future artifacts. Linux checksum manifests are signed in the
protected release environment. Windows and macOS artifacts are distributed
with checksums but remain unsigned and not notarized under the current policy.

## Compatibility and publication boundary

The minimum supported Codex CLI remains `0.145.0`; `0.146.0` is the recommended
verified version. The App Server contract remains experimental, and newer
versions must pass the runtime compatibility handshake.

An actual `v1.0.2` publication still requires the exact candidate SHA, protected
source/renderer/persistence/package gates, cross-platform inventory, updater
metadata and the release workflow's explicit authorization. This follow-up
creates no tag, release or uploaded asset.
